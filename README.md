 PaidGPT 🤖

PaidGPT is a modern AI-powered web application built using the MERN Stack.  
It provides an intelligent AI chatbot experience along with AI image generation features in a clean and user-friendly interface.

Users can chat with AI, generate creative images, manage conversations, and enjoy a fast and responsive experience across all devices.

---

## 🚀 Features

- 💬 AI Chatbot
- 🎨 AI Image Generation
- 🔐 User Authentication & Authorization
- 🌙 Modern Responsive UI
- ⚡ Fast & Smooth Performance
- 📱 Mobile Friendly Design
- 🗂️ Chat History Management
- ☁️ MERN Stack Architecture
- 🔒 Secure Backend APIs

---
